1기본 타입 (Primitive Type)

자바는 8개의 기본형(primitive type)을 언어 차원에서 제공합니다. 기본형은 객체가 아니라 값 자체를 저장하며, 크기가 고정되어 있습니다.

분류타입기본값비고
정수형byte0가장 작은 정수, 파일 바이트 처리 등에 사용
short0실무에서는 드물게 사용
int0가장 많이 쓰는 기본 정수형
long0L큰 수(예: 밀리초 타임스탬프), 리터럴 끝에 L
실수형float0.0F정밀도 낮음, 리터럴 끝에 F
double0.0가장 많이 쓰는 기본 실수형
문자형char'\u0000'작은따옴표 'A', 내부적으로 정수(유니코드 코드값)로 취급됨
논리형booleanfalsetrue / false만 가능
PrimitiveDemo.java
public class PrimitiveDemo {
    public static void main(String[] args) {
        int i = 10;
        long l = i;          // 묵시적(자동) 형변환: int → long (작은 것 → 큰 것)
        double d = l;         // long → double 도 자동

        double pi = 3.14;
        int truncated = (int) pi;   // 명시적 캐스팅 필요: double → int (소수점 버림)
        System.out.println(truncated);  // 3

        byte b = (byte) 130;          // int 130을 byte로 강제 변환 → 범위 초과로 값이 깨짐
        System.out.println(b);          // -126 (오버플로우)

        char c = 'A';
        int code = c;                    // char → int : 유니코드 값 65
        System.out.println(code);
        System.out.println((char)(c + 1)); // 'B' - 문자에 정수 연산 가능
    }
}

2조건문 — if / switch

IfSwitchDemo.java
public class IfSwitchDemo {
    public static void main(String[] args) {
        int score = 85;

        // if - else if - else : 범위 조건에 적합
        if (score >= 90) System.out.println("A");
        else if (score >= 80) System.out.println("B");   // 여기 실행됨
        else System.out.println("C");

        // switch (전통 방식) : break 필수, 없으면 fall-through
        int day = 3;
        switch (day) {
            case 1: System.out.println("월"); break;
            case 2: System.out.println("화"); break;
            case 3: System.out.println("수"); break;   // 여기서 멈춤
            default: System.out.println("그 외");
        }

        // switch expression (Java 14+) : 화살표(->), break 불필요, 값 반환 가능
        String result = switch (day) {
            case 1, 7 -> "주말 근처";
            case 2, 3, 4, 5, 6 -> "평일";
            default -> "알 수 없음";
        };
        System.out.println(result);
    }
}
실행결과
B
수
평일
switch는 값이 몇 가지로 딱 떨어질 때(요일, 메뉴 번호, enum 등) if-else 체인보다 읽기 좋습니다. 반면 범위 비교(score >= 80 같은)는 if로만 표현할 수 있습니다.

3반복문 — for / while

반복문조건 검사 시점특징
for매 반복 전초기화·조건·증감이 한 줄에 모여있어 횟수가 명확할 때 적합
while매 반복 전조건이 언제 끝날지 모를 때(입력 대기 등) 적합, 0번 실행될 수도 있음
do-while매 반복 후본문을 최소 1번은 반드시 실행(예: 메뉴 최초 1회 표시)
향상된 for(for-each)-for(타입 변수 : 배열/컬렉션) — 인덱스 없이 순회, 값 변경/인덱스 필요시 부적합
LoopDemo.java
public class LoopDemo {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {          // 정확히 3번 반복
            System.out.println("for: " + i);
        }

        int n = 3;
        while (n > 0) {                          // 조건이 거짓이면 한 번도 안 돌 수 있음
            System.out.println("while: " + n);
            n--;
        }

        int m = 0;
        do {                                        // 조건과 무관하게 최소 1번 실행
            System.out.println("do-while: " + m);
            m++;
        } while (m < 0);   // 처음부터 거짓이지만 이미 1번은 실행됨

        for (int i = 1; i <= 5; i++) {
            if (i == 3) continue;   // 3만 건너뜀
            if (i == 5) break;       // 5에서 반복문 완전히 종료
            System.out.print(i + " ");
        }
    }
}

41차원 배열

배열은 같은 타입의 값을 고정 개수만큼, 메모리에 연속으로 저장하는 자료구조입니다. 한 번 크기를 정하면 바꿀 수 없습니다(크기 변경이 필요하면 ArrayList 사용).

Array1DDemo.java
public class Array1DDemo {
    public static void main(String[] args) {
        int[] a = new int[5];         // 크기 5, 기본값 0으로 초기화됨: [0,0,0,0,0]
        int[] b = {10, 20, 30, 40};   // 선언과 동시에 초기화

        for (int i = 0; i < b.length; i++) {   // length는 배열의 "속성"(메서드 아님, 괄호 없음)
            System.out.print(b[i] + " ");
        }
        System.out.println();

        int sum = 0;
        for (int v : b) sum += v;      // 향상된 for : 값만 필요할 때 간결
        System.out.println("합계: " + sum);

        // 배열 뒤집기
        for (int i = 0; i < b.length / 2; i++) {
            int tmp = b[i];
            b[i] = b[b.length - 1 - i];
            b[b.length - 1 - i] = tmp;
        }
        System.out.println(java.util.Arrays.toString(b));
    }
}
실행결과

합계: 100
[40, 30, 20, 10]
배열 범위 초과(ArrayIndexOutOfBoundsException)는 자바에서 가장 흔한 런타임 에러 중 하나입니다. 반복문에서 i <= arr.length처럼 =를 실수로 넣지 않도록 항상 i < arr.length를 확인하세요.

52차원 배열 구조와 원리

자바의 2차원 배열은 사실 "배열의 배열(array of arrays)"입니다. 바깥 배열의 각 칸이 숫자를 담는 게 아니라, 또 다른 1차원 배열의 주소(참조)를 담고 있습니다.

Array2DBasics.java
public class Array2DBasics {
    public static void main(String[] args) {
        int[][] arr = new int[3][4];       // 3행 4열, 모두 0으로 초기화
        int[][] arr2 = {                     // 선언과 동시에 초기화
            {1, 2, 3},
            {4, 5, 6}
        };
        int[][] jagged = {                   // 행마다 길이가 다른 "가변 배열"도 가능
            {1},
            {1, 2},
            {1, 2, 3}
        };

        System.out.println(arr.length);       // 3 (행의 개수, 바깥 배열 길이)
        System.out.println(arr[0].length);      // 4 (0번째 행의 길이)

        for (int i = 0; i < arr2.length; i++) {          // 행
            for (int j = 0; j < arr2[i].length; j++) {      // 열 (행마다 따로 length 확인!)
                System.out.print(arr2[i][j] + " ");
            }
            System.out.println();
        }

        for (int[] row : jagged) System.out.println(java.util.Arrays.toString(row));
    }
}

이중 for문 순회 규칙: 바깥 for는 행(row, i)을, 안쪽 for는 열(column, j)을 도는 것이 관례입니다. 가변 배열일 수 있으므로 안쪽 반복 조건은 arr[0].length가 아니라 arr[i].length로 매번 그 행의 길이를 확인하는 것이 안전합니다.

62차원 배열의 용도

2차원 배열은 "행과 열로 이루어진 모든 데이터"를 표현할 때 사용합니다. 1차원 배열로는 어색하거나 불가능한 관계를 자연스럽게 담을 수 있습니다.

용도행(row)이 의미하는 것열(column)이 의미하는 것
성적표학생 한 명과목별 점수
게임판(틱택토, 지뢰찾기, 오목)세로 좌표가로 좌표
이미지/픽셀Y좌표(세로)X좌표(가로), 값은 색상/밝기
미로·격자 탐색(DFS/BFS)격자의 행격자의 열, 값은 벽(1)/길(0)
행렬(수학) 연산행 벡터열 성분
달력주(week)요일
Array2DUsage.java — 성적표 예제(학생×과목)
public class Array2DUsage {
    public static void main(String[] args) {
        String[] students = {"철수", "영희", "민수"};
        String[] subjects = {"국어", "영어", "수학"};
        int[][] scores = {              // scores[학생번호][과목번호]
            {80, 90, 70},
            {95, 85, 100},
            {60, 75, 80}
        };

        for (int i = 0; i < students.length; i++) {   // 행 = 학생
            int sum = 0;
            for (int j = 0; j < subjects.length; j++) {  // 열 = 과목
                sum += scores[i][j];
            }
            double avg = sum / (double) subjects.length;
            System.out.printf("%s 평균: %.1f%n", students[i], avg);
        }

        // 과목별(열) 합계 — "열 방향"으로 훑으려면 바깥/안쪽을 반대로 순회
        for (int j = 0; j < subjects.length; j++) {
            int subjectSum = 0;
            for (int i = 0; i < students.length; i++) {
                subjectSum += scores[i][j];
            }
            System.out.println(subjects[j] + " 총점: " + subjectSum);
        }
    }
}

2차원 배열의 진짜 힘은 "행 우선으로도, 열 우선으로도 자유롭게 순회할 수 있다"는 점입니다 — 위 예제처럼 scores[i][j]는 그대로 두고 반복문의 바깥/안쪽 순서만 바꾸면 "학생별 평균"과 "과목별 총점"을 둘 다 구할 수 있습니다.

72차원 배열 시계방향 회전

N×M 배열을 시계방향으로 90도 돌리면, 결과는 M×N 크기가 되고 각 원소는 다음 규칙으로 이동합니다:

result[j][N-1-i] = original[i][j]   (N = 원본의 행 개수)

핵심 관찰: 시계방향 회전은 "각 열을 아래→위 순서로 읽어, 새 배열의 각 행으로 채우는 것"과 같다

RotateClockwise.java
import java.util.Arrays;

public class RotateClockwise {
    public static void main(String[] args) {
        int[][] original = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };
        int[][] rotated = rotateClockwise(original);
        for (int[] row : rotated) System.out.println(Arrays.toString(row));
    }

    static int[][] rotateClockwise(int[][] arr) {
        int n = arr.length;         // 원본 행 개수
        int m = arr[0].length;      // 원본 열 개수
        int[][] result = new int[m][n];   // 결과는 행/열이 뒤바뀐 m×n 크기

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                result[j][n - 1 - i] = arr[i][j];   // 핵심 공식
            }
        }
        return result;
    }
}
실행결과
[7, 4, 1]
[8, 5, 2]
[9, 6, 3]

82차원 배열 반시계방향 회전

반시계방향(90도)은 시계방향과 정반대 방향으로 대응됩니다:

result[M-1-j][i] = original[i][j]   (M = 원본의 열 개수)

핵심 관찰: 반시계방향 회전은 "각 열을 위→아래 순서로 읽되, 오른쪽 열부터 새 배열의 행으로 채우는 것"과 같다 (시계방향과 정확히 대칭)

RotateCounterClockwise.java
import java.util.Arrays;

public class RotateCounterClockwise {
    public static void main(String[] args) {
        int[][] original = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };
        int[][] rotated = rotateCCW(original);
        for (int[] row : rotated) System.out.println(Arrays.toString(row));
    }

    static int[][] rotateCCW(int[][] arr) {
        int n = arr.length;          // 원본 행 개수
        int m = arr[0].length;       // 원본 열 개수
        int[][] result = new int[m][n];    // 결과는 m×n 크기 (시계방향과 동일)

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                result[m - 1 - j][i] = arr[i][j];   // 핵심 공식 (시계방향과 좌우가 다름)
            }
        }
        return result;
    }
}

공식result[j][N-1-i] = arr[i][j]result[M-1-j][i] = arr[i][j]
결과 크기M×N (행/열이 뒤바뀜)M×N (행/열이 뒤바뀜)
원본 왼쪽위(0,0)의 행선결과의 오른쪽 위 모서리로결과의 왼쪽 아래 모서리로
기억법"열을 세로로 읽어 → 결과의 가로 줄로, 아래에서 위로""열을 세로로 읽어 → 결과의 가로 줄로, 위에서 아래로, 오른쪽 열부터"
두 공식 모두 "바깥 for는 원본의 행 i, 안쪽 for는 원본의 열 j"를 그대로 돌면서 대입되는 위치(왼쪽 result[...])만 바뀐다는 점이 같습니다. 회전 방향을 헷갈릴 때는 3×3 예제로 손으로 한 번 직접 옮겨보는 것이 가장 빠릅니다.

9종합 체크리스트

  • 8개 기본형(byte/short/int/long/float/double/char/boolean)의 크기와 기본값을 안다
  • 묵시적(자동) 형변환과 명시적 캐스팅의 차이, 캐스팅 시 값 손실 가능성을 안다
  • if-else 체인(범위 조건)과 switch(값별 분기, break/fall-through, 화살표식)의 쓰임을 구분한다
  • for(횟수 명확)/while(조건 기반, 0번 가능)/do-while(최소 1번)의 차이를 안다
  • 1차원 배열이 메모리에 연속으로 저장되어 인덱스 접근이 O(1)이라는 것을 안다
  • 2차원 배열이 "배열의 배열"이며, 바깥 배열이 각 행 배열의 참조를 담는다는 구조를 설명할 수 있다
  • 가변 배열(jagged array)이 가능하며 안쪽 반복에서 arr[i].length를 써야 안전한 이유를 안다
  • 2차원 배열이 성적표·게임판·이미지·격자탐색·행렬 등 "행-열 관계"를 표현하는 데 쓰인다는 것을 안다
  • 행 우선/열 우선으로 반복문 순서만 바꿔 같은 데이터를 다르게 집계할 수 있음을 안다
  • 시계방향 회전 공식 result[j][N-1-i]=arr[i][j]을 그림과 함께 설명할 수 있다
  • 반시계방향 회전 공식 result[M-1-j][i]=arr[i][j]을 그림과 함께 설명할 수 있다
  • 두 회전 공식이 "대입 위치만 다르고 순회 구조는 같다"는 공통점을 안다
