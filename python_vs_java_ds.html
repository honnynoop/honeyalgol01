🐍 Python의 특징

  • 동적 타입 — list에 혼합 타입 저장 가능
  • 내장 자료구조가 강력하고 직관적
  • list comprehension으로 간결한 생성
  • GIL 때문에 멀티스레드 성능 주의
  • dict는 삽입 순서를 보장 (Python 3.7+)

☕ Java의 특징

  • 정적 타입 — 제네릭으로 타입 안전성 보장
  • Collection 프레임워크로 체계적 구조
  • interface 기반 (List, Map, Set, Queue)
  • primitive 배열 (int[])과 객체 배열 구분
  • Collections, Arrays 유틸리티 클래스 풍부

⚡ 성능 비교

  • 랜덤 접근: 동등 O(1) — list vs ArrayList
  • 해시 조회: 동등 O(1) — dict vs HashMap
  • Java는 JIT 컴파일로 반복 작업 빠름
  • Python은 numpy로 수치연산 보완
  • 메모리: Java 객체 오버헤드 > Python

연결 리스트

노드가 포인터로 연결된 선형 자료구조

Python
직접 구현 / collections.deque
표준 라이브러리에 LinkedList 없음
# 노드 직접 구현
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None

    def append(self, data):
        node = Node(data)
        if not self.head:
            self.head = node
            return
        cur = self.head
        while cur.next:
            cur = cur.next
        cur.next = node

# 실용적으론 deque 사용
from collections import deque
dq = deque([1, 2, 3])
dq.appendleft(0)  # O(1)
dq.popleft()      # O(1)

LIFO와 FIFO 원칙의 선형 자료구조

list (append / pop)

queue = deque()

queue.append(2)
queue.popleft()    # dequeue O(1) → 1

# queue.Queue (스레드 안전)

// 스택 (레거시 — 비권장)

집합 (Set)

중복 없는 원소의 컬렉션

Python
set / frozenset
# 생성
s = {1, 2, 3}
s = set([1, 2, 2, 3])  # → {1,2,3}

# 연산
s.add(4)
s.discard(2)    # 없어도 에러 없음
s.remove(1)    # 없으면 KeyError

# 집합 연산 (매우 직관적!)
a = {1, 2, 3}
b = {2, 3, 4}
a | b    # 합집합 {1,2,3,4}
a & b    # 교집합 {2,3}
a - b    # 차집합 {1}
a ^ b    # 대칭차 {1,4}

# 불변 set
fs = frozenset([1, 2, 3])
Java
HashSet / TreeSet / LinkedHashSet
// HashSet — 순서 없음
Set<Integer> set = new HashSet<>();
set.add(1); set.add(2); set.add(3);
set.add(2);   // 중복 무시
set.remove(1);
set.contains(2);   // true

// TreeSet — 정렬 유지
Set<Integer> ts = new TreeSet<>();
ts.add(3); ts.add(1); ts.add(2);
// → [1, 2, 3] 자동 정렬

// 집합 연산 (Java는 직접)
Set<Integer> a = new HashSet<>(...);
Set<Integer> b = new HashSet<>(...);

a.addAll(b);     // 합집합
a.removeAll(b);  // 차집합
// 집합 연산 시각화

A & B → {2,3} 교집합
A - B → {1,A} 차집합
A ^ B → {1,4,A,B} 대칭차

트리

계층적 비선형 자료구조

Python — BST 직접 구현
# 이진 탐색 트리 (직접 구현)
class TreeNode:
    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None

def inorder(root):
    if not root: return
    inorder(root.left)
    print(root.val)
    inorder(root.right)

# 정렬된 컨테이너 (SortedList)
from sortedcontainers import SortedList
sl = SortedList([3,1,4,1,5])
sl.add(2)   # 자동 정렬 삽입

# heapq — 최소 힙
import heapq
h = [3, 1, 4]
heapq.heapify(h)
heapq.heappush(h, 2)
heapq.heappop(h)   # → 1
Java — TreeMap / TreeSet / PriorityQueue
// 이진 탐색 트리 (직접 구현)
class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int v) { val = v; }
}

// TreeMap — Red-Black Tree 기반
TreeMap<Integer, String> tm =
    new TreeMap<>();
tm.put(3, "c");
tm.put(1, "a");
tm.put(2, "b");
tm.firstKey();   // 1 (최솟값)
tm.lastKey();    // 3 (최댓값)
tm.floorKey(2); // ≤2 중 최대

// PriorityQueue — 최소 힙
PriorityQueue<Integer> pq =
    new PriorityQueue<>();
pq.offer(3); pq.offer(1);
pq.poll();   // → 1 (최솟값)
// 이진 탐색 트리 시각화 [5,3,7,1,4,6,8]
