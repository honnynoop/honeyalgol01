1컬렉션 프레임워크 개관

자바의 자료구조는 java.util 패키지의 인터페이스 계층 위에 구현체가 얹히는 구조입니다. 핵심은 Collection과 Map 두 계열이 서로 상속관계가 아니라는 점입니다.

Collection(List/Set/Queue)과 Map은 서로 다른 뿌리 — Map은 "키-값 쌍"을 다루므로 원소 하나를 다루는 Collection과 설계가 다르다
※ UML 표기 규칙: 속이 빈 삼각형 화살표는 항상 자식(하위 인터페이스) → 부모(상위 인터페이스) 방향, 화살표 끝이 부모 쪽에 붙는다

인터페이스특징대표 구현체
List순서 O, 중복 O, 인덱스 접근ArrayList, LinkedList, Vector
Set순서 X(구현체별 상이), 중복 XHashSet, LinkedHashSet, TreeSet
QueueFIFO(선입선출), 일부는 우선순위LinkedList, ArrayDeque, PriorityQueue
Deque양쪽 끝 입출력(Queue+Stack 겸용)ArrayDeque, LinkedList
Map키-값 쌍, 키 중복 XHashMap, LinkedHashMap, TreeMap
선택 기준 한 줄 요약: 순서+중복 허용→List, 중복 제거→Set, 키로 찾기→Map, 처리 순서 관리(FIFO/LIFO/우선순위)→Queue·Deque.

import java.util.*;

public class ListDemo {
    public static void main(String[] args) {
        List<String> arr = new ArrayList<>();
        arr.add("A"); arr.add("B"); arr.add("C");
        arr.add(1, "X");                 // 인덱스 1에 삽입 → [A, X, B, C]
        System.out.println(arr);
        System.out.println(arr.get(2));  // "B"

        linked.addFirst("HEAD");          // 맨 앞 O(1) 삽입
        linked.addLast("TAIL");            // 맨 뒤 O(1) 삽입
        System.out.println(linked);

        Collections.sort(arr);              // 사전순 정렬
        System.out.println(arr);
    }
}

5Queue — Deque / PriorityQueue

Queue는 FIFO(First In First Out, 선입선출)가 기본 원칙입니다. PriorityQueue만 예외적으로 "우선순위가 높은 것부터" 나옵니다.

메서드일반형(예외 던짐)안전형(값 반환)
추가add(e)offer(e)
꺼내기(제거)remove()poll() — 비었으면 null
맨앞 확인(유지)element()peek() — 비었으면 null
QueueDemo.java
import java.util.*;

public class QueueDemo {
    public static void main(String[] args) {
        Queue<Integer> q = new ArrayDeque<>();
        q.offer(1); q.offer(2); q.offer(3);
        System.out.println(q.poll());  // 1 (먼저 넣은 게 먼저 나옴)
        System.out.println(q.peek());  // 2 (제거 안 하고 확인만)

        PriorityQueue<Integer> pq = new PriorityQueue<>();          // 기본: 최소힙
        pq.offer(5); pq.offer(1); pq.offer(3);
        System.out.println(pq.poll());  // 1 (가장 작은 값부터)

        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder()); // 최대힙
        maxHeap.offer(5); maxHeap.offer(1); maxHeap.offer(3);
        System.out.println(maxHeap.poll());  // 5
    }
}

6Stack — LIFO 구조

Stack은 LIFO(Last In First Out, 후입선출)입니다. java.util.Stack은 legacy(Vector 상속, 동기화로 느림)라, 실무에서는 Deque(ArrayDeque)를 스택으로 쓰는 것이 권장됩니다.

메서드Deque(권장)Stack(legacy)
넣기push(e)push(e)
빼기pop()pop()
확인만peek()peek()
비었는지isEmpty()empty()
StackDemo.java
import java.util.*;

public class StackDemo {
    public static void main(String[] args) {
        Deque<Integer> stack = new ArrayDeque<>();   // 스택으로 사용 (권장 방식)
        stack.push(1); stack.push(2); stack.push(3);
        System.out.println(stack.pop());   // 3 - 가장 나중에 넣은 게 먼저 나옴
        System.out.println(stack.peek());  // 2 - 제거하지 않고 확인
        System.out.println(stack);          // [2, 1]
    }
}

7Comparable vs Comparator

둘 다 "정렬 기준"을 정의하지만, 어디에 정의하느냐가 다릅니다.

ComparableComparator
정의 위치정렬 대상 클래스 내부(implements Comparable<T>)클래스 외부(별도 클래스 또는 람다)
메서드compareTo(T o)compare(T a, T b)
기준 개수1개(자연 순서, natural ordering)여러 개 자유롭게 정의 가능
사용 예Collections.sort(list)Collections.sort(list, comparator)
ComparableComparator.java
import java.util.*;

class Student implements Comparable<Student> {   // Comparable: 클래스 내부에 "기본 정렬 기준" 1개
    String name; int score;
    Student(String name, int score) { this.name = name; this.score = score; }

    @Override
    public int compareTo(Student o) {
        return this.score - o.score;   // 점수 오름차순이 "자연 순서"
    }
    @Override public String toString() { return name + "(" + score + ")"; }
}

public class ComparableComparator {
    public static void main(String[] args) {
        List<Student> list = new ArrayList<>(List.of(
            new Student("영희", 85), new Student("철수", 70), new Student("민수", 85)
        ));

        Collections.sort(list);   // Comparable 기준(점수 오름차순)
        System.out.println("자연순서: " + list);

        // Comparator: 이름 오름차순, 점수 같으면 상관없음 - 외부에서 자유롭게 기준 교체
        list.sort(Comparator.comparing((Student s) -> s.name));
        System.out.println("이름순: " + list);

        // 점수 내림차순, 같으면 이름 오름차순 (다중 기준 체이닝)
        list.sort(Comparator.comparingInt((Student s) -> s.score).reversed()
                             .thenComparing(s -> s.name));
        System.out.println("점수내림차순+이름오름차순: " + list);
    }
}
실행결과
자연순서: [철수(70), 영희(85), 민수(85)]
이름순: [민수(85), 영희(85), 철수(70)]
점수내림차순+이름오름차순: [민수(85), 영희(85), 철수(70)]
Comparator.comparing(), .reversed(), .thenComparing() 체이닝은 실무·코딩테스트에서 가장 많이 쓰는 정렬 패턴입니다. TreeSet/TreeMap/PriorityQueue 생성자에도 그대로 Comparator를 넘길 수 있습니다.

8DFS (깊이우선탐색)

DFS는 "한 방향으로 갈 수 있는 만큼 깊이 들어갔다가, 막히면 되돌아오는(백트랙)" 탐색입니다. 재귀 호출 스택이 곧 탐색 경로가 됩니다.

DFSDemo.java (인접리스트 그래프, 재귀)
import java.util.*;

public class DFSDemo {
    static List<List<Integer>> graph;
    static boolean[] visited;

    public static void main(String[] args) {
        int n = 6;
        graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        addEdge(1,2); addEdge(1,5); addEdge(2,3); addEdge(2,4);

        visited = new boolean[n];
        dfs(1);
    }
    static void addEdge(int a, int b) { graph.get(a).add(b); graph.get(b).add(a); }

    static void dfs(int cur) {
        visited[cur] = true;
        System.out.print(cur + " ");
        for (int next : graph.get(cur)) {
            if (!visited[next]) dfs(next);   // 재귀 = 스택에 쌓임
        }
    }
}
실행결과
1 2 3 4 5
재귀 대신 스택으로도 구현 가능: Deque<Integer> stack에 push/pop을 직접 다루면 같은 순서(구현에 따라 방문순서는 약간 달라질 수 있음)로 반복문만으로 DFS를 흉내낼 수 있습니다 — "재귀 = 시스템이 대신 관리해주는 스택"이라는 것이 핵심입니다.

9BFS (너비우선탐색)

BFS는 "가까운 것부터 한 단계씩 넓게" 탐색합니다. Queue를 사용해 레벨(단계) 순서대로 방문합니다. 최단 거리(가중치 없는 그래프)를 구할 때 사용합니다.

BFSDemo.java
import java.util.*;

public class BFSDemo {
    public static void main(String[] args) {
        int n = 6;
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        addEdge(graph, 1,2); addEdge(graph, 1,3); addEdge(graph, 2,4); addEdge(graph, 2,5);

        boolean[] visited = new boolean[n];
        Queue<Integer> q = new ArrayDeque<>();
        q.offer(1);
        visited[1] = true;

        while (!q.isEmpty()) {
            int cur = q.poll();
            System.out.print(cur + " ");
            for (int next : graph.get(cur)) {
                if (!visited[next]) {
                    visited[next] = true;   // 큐에 넣을 때 바로 방문 처리 (중복 삽입 방지)
                    q.offer(next);
                }
            }
        }
    }
    static void addEdge(List<List<Integer>> g, int a, int b) { g.get(a).add(b); g.get(b).add(a); }
}
실행결과
1 2 3 4 5
DFS vs BFS 선택 기준: 모든 경로를 다 확인해야 하거나 백트래킹이 필요하면 DFS(재귀), 최단거리·최소횟수를 구해야 하면 BFS(큐)를 씁니다.

10Flood Fill

그림판의 "페인트 통" 기능처럼, 2차원 격자에서 같은 값을 가진 연결된 영역 전체를 DFS 또는 BFS로 찾아 바꾸는 기법입니다.

FloodFillDemo.java (DFS 버전)
public class FloodFillDemo {
    static int[][] grid = {
        {0,0,1},
        {0,1,1}
    };
    static int rows = grid.length, cols = grid[0].length;
    static int[] dx = {-1,1,0,0}, dy = {0,0,-1,1};   // 상하좌우

    public static void main(String[] args) {
        floodFill(0, 0, 0, 2);   // (0,0)에서 시작, 0을 2로 채운다
        for (int[] row : grid) {
            for (int v : row) System.out.print(v + " ");
            System.out.println();
        }
    }

    static void floodFill(int x, int y, int target, int newColor) {
        if (x < 0 || x >= rows || y < 0 || y >= cols) return;   // 범위 밖
        if (grid[x][y] != target) return;                          // 다른 색이면 멈춤
        grid[x][y] = newColor;                                       // 색칠(=방문처리 겸용)
        for (int d = 0; d < 4; d++) {
            floodFill(x + dx[d], y + dy[d], target, newColor);        // 4방향 재귀 = DFS
        }
    }
}
실행결과
2 2 1 
2 1 1
배열 값 자체를 바꾸는 것이 visited[] 역할을 겸하므로 별도의 방문 배열 없이도 무한루프를 막을 수 있습니다. 재귀 깊이가 너무 깊어질 수 있는 큰 격자에서는 DFS 대신 BFS(Queue) 버전을 쓰는 것이 안전합니다.

11Backtracking (백트래킹)

백트래킹은 "선택 → 조건 확인 → 안 되면 되돌리고 다른 선택"을 반복하는 DFS의 응용입니다. 가능성이 없는 가지는 더 들어가지 않고 가지치기(pruning)합니다.

BacktrackTemplate.java — 공통 뼈대
// 백트래킹 공통 템플릿
void backtrack(상태) {
    if (조건 만족) { 결과 저장; return; }
    for (선택지 : 가능한 선택들) {
        if (조건에 맞지 않으면) continue;   // 가지치기
        선택한다;                             // 상태 변경
        backtrack(다음 상태);                  // 더 깊이 탐색
        선택을 취소한다;                       // 되돌리기(백트랙) — 핵심!
    }
}
NQueenDemo.java (4-Queen — 서로 공격하지 않게 4개 놓기)
public class NQueenDemo {
    static int n = 4;
    static int[] col = new int[n];   // col[row] = 그 행에 놓인 퀸의 열
    static int count = 0;

    public static void main(String[] args) {
        backtrack(0);
        System.out.println("4-Queen 해의 개수: " + count);
    }

    static void backtrack(int row) {
        if (row == n) { count++; return; }              // 모든 행에 성공적으로 놓음
        for (int c = 0; c < n; c++) {
            if (isSafe(row, c)) {                          // 가지치기: 공격 가능하면 스킵
                col[row] = c;                                // 선택
                backtrack(row + 1);                           // 다음 행 탐색
                // col[row]는 다음 반복에서 덮어써지므로 별도 취소 코드 불필요
            }
        }
    }

    static boolean isSafe(int row, int c) {
        for (int r = 0; r < row; r++) {
            if (col[r] == c) return false;                    // 같은 열
            if (Math.abs(col[r] - c) == Math.abs(r - row)) return false;  // 같은 대각선
        }
        return true;
    }
}

12순열 (Permutation)

순열은 순서를 구별해서 n개 중 r개를 뽑아 배열하는 경우입니다(nPr). "이미 쓴 원소"를 visited[]로 표시하며 재귀합니다.

PermutationDemo.java
import java.util.*;

public class PermutationDemo {
    static int n = 3;
    static int[] nums = {1, 2, 3};
    static int[] path = new int[n];
    static boolean[] used = new boolean[n];

    public static void main(String[] args) {
        permute(0);
    }

    static void permute(int depth) {
        if (depth == n) {
            System.out.println(Arrays.toString(path));
            return;
        }
        for (int i = 0; i < n; i++) {
            if (used[i]) continue;          // 이미 쓴 원소는 건너뜀
            used[i] = true;                   // 선택
            path[depth] = nums[i];
            permute(depth + 1);                // 다음 자리로
            used[i] = false;                    // 백트랙(취소) — 다른 조합을 위해 되돌림
        }
    }
}

13조합 (Combination)

조합은 순서를 구별하지 않고 n개 중 r개를 뽑는 경우입니다(nCr). "시작 인덱스(start)"를 넘겨 이미 지나간 원소는 다시 고르지 않도록 합니다.

CombinationDemo.java
import java.util.*;

public class CombinationDemo {
    static int n = 4, r = 2;
    static int[] nums = {1, 2, 3, 4};
    static int[] path = new int[r];

    public static void main(String[] args) {
        combine(0, 0);
    }

    static void combine(int start, int depth) {
        if (depth == r) {
            System.out.println(Arrays.toString(path));
            return;
        }
        for (int i = start; i < n; i++) {     // start부터 시작 → 순서 구별 없이, 중복 조합 방지
            path[depth] = nums[i];
            combine(i + 1, depth + 1);           // 다음엔 i+1부터만 고른다 (i를 다시 못 고름)
        }
    }
}
실행결과 (4C2 = 6가지)

[1, 3]
[1, 4]
[2, 3]
[2, 4]
[3, 4]
순열과의 차이는 단 하나: 순열은 매번 0부터 "안 쓴 것"을 모두 후보로 보고(visited[]), 조합은 start부터만 후보로 봅니다(이미 지나간 인덱스는 다시 보지 않음) — 그래서 [1,2]와 [2,1]을 조합에서는 같은 것으로 취급(한 번만 생성)합니다.

14부분집합 (Power Set)

부분집합(멱집합)은 각 원소를 "포함한다/안 한다" 두 가지로 결정하는 문제입니다. 원소가 n개면 부분집합은 2ⁿ개입니다. 재귀(포함/제외) 방식과 비트마스크 방식 두 가지를 모두 봅니다.

PowerSetRecursive.java — 포함/제외 재귀
import java.util.*;

public class PowerSetRecursive {
    static int[] nums = {1, 2, 3};
    static List<Integer> path = new ArrayList<>();

    public static void main(String[] args) {
        go(0);
    }

    static void go(int idx) {
        if (idx == nums.length) {
            System.out.println(path);       // 매 리프가 하나의 부분집합(빈 집합 포함)
            return;
        }
        path.add(nums[idx]);                 // 포함하는 경우
        go(idx + 1);
        path.remove(path.size() - 1);         // 백트랙(취소)
        go(idx + 1);                            // 포함하지 않는 경우
    }
}

PowerSetBitmask.java — 비트마스크 방식
public class PowerSetBitmask {
    public static void main(String[] args) {
        int[] nums = {1, 2, 3};
        int n = nums.length;

        for (int mask = 0; mask < (1 << n); mask++) {   // 0 ~ 2^n-1 모든 비트조합
            StringBuilder sb = new StringBuilder("[");
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) sb.append(nums[i]).append(" ");   // i번째 비트가 1이면 포함
            }
            sb.append("]");
            System.out.println(sb);
        }
    }
}

비트마스크 방식은 재귀 없이 반복문만으로 부분집합을 생성할 수 있어 n이 20 이하로 작을 때 코딩테스트에서 매우 자주 쓰입니다 — mask의 각 비트 하나하나가 원소 하나의 포함 여부와 정확히 대응합니다.

15종합 체크리스트

  • Collection(List/Set/Queue)과 Map이 서로 다른 계층(Map은 Collection 상속 X)이라는 것을 안다
  • ArrayList(배열, 인덱스O(1))와 LinkedList(노드+포인터, 양끝O(1))의 구조·시간복잡도 차이를 안다
  • HashSet(무순서)/LinkedHashSet(입력순)/TreeSet(정렬) 내부 구조(해시테이블/연결리스트/RB트리)와 차이를 안다
  • HashMap/LinkedHashMap/TreeMap의 구조 차이와 merge·computeIfAbsent 같은 실전 API를 쓸 수 있다
  • Queue(FIFO)와 PriorityQueue(힙, 우선순위)의 차이, offer/poll/peek 사용법을 안다
  • Stack(LIFO)의 push/pop 원리와 Deque(ArrayDeque)를 스택으로 쓰는 이유를 안다
  • Comparable(클래스 내부, 자연순서 1개)과 Comparator(외부, 여러 기준·체이닝) 차이를 설명할 수 있다
  • DFS(재귀/스택, 깊이 우선, 백트랙)와 BFS(큐, 레벨 순서, 최단거리)를 구분해 구현할 수 있다
  • Flood Fill이 DFS/BFS의 응용이며 배열 값 변경이 방문처리를 겸한다는 것을 안다
  • 백트래킹 템플릿(선택→탐색→취소)과 가지치기(pruning)의 역할을 이해한다
  • 순열(visited[], 매번 전체 후보)과 조합(start 인덱스, 지나간 것 제외)의 구현 차이를 안다
  • 부분집합을 재귀(포함/제외)와 비트마스크(0~2ⁿ-1) 두 방식으로 모두 만들 수 있다
